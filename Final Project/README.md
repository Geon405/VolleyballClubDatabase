# Comp353 Final Project
[![Status](https://img.shields.io/badge/status-In%20Development-red.svg)]() [![Version](https://img.shields.io/badge/version-0.0.1-blue.svg)]()

## Overview

This project is a final for **COMP353**. It manages and queries a database for a **Montreal Youth Volleyball Club (MYVC)** system. The repository is structured to separate backend database logic from the frontend user interface.

---

## Features

### Backend
- SQL scripts to initialize and populate the database.
- PHP logic for secure database connection and query execution.

### Frontend
- User-friendly interface to interact with the database.
- Display of query results dynamically using PHP, HTMX and HTML.

---

## Predefined Queries

The project supports the following queries:

1. **Location Details**: Lists locations sorted by province and city.
2. **Family Members Report**: Displays families with active club members.
3. **Personnel Details**: Shows details of active personnel.
4. **Club Members List**: Lists club members by location and age.
5. **Member Payments**: Displays payment history ordered by date.

---

## Technologies Used

- **PHP**: Backend scripting and database interactions.
- **MySQL**: Database management.
- **HTML/CSS**: Frontend interface.
- **HTMX**: Light JS library for AJAX handling & dynamic page updates.
